# 第 13 章：微调、对齐与推理

> 章节目标：理解预训练模型如何通过监督数据、参数高效方法、偏好信号和 decoding 变成可用系统。

## 本章结构

| 小节 | 要回答的问题 | 主要产出 |

## 重要边界

- SFT 不是“把 prompt 和 answer 拼起来然后无条件平均 loss”；常见指令微调会屏蔽 prompt token，只对 assistant target 计损失。
- LoRA 减少可训练参数，不会自动减少所有训练显存；冻结基座、优化器状态和激活仍需计算/存储。
- DPO 是对偏好对的相对优化目标，不等于拥有完美的奖励模型。
- decoding 改变的是推理时的选择策略，不会改变已经训练好的参数。

你能构造 response mask，计算一个 LoRA 层的参数量，写出 DPO 的单样本 loss，并在固定 logits 下解释 temperature、top-k 与 top-p 的差异。
