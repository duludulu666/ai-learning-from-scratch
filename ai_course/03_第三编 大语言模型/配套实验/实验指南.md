## 运行方式

每个 `lab_章_节.py` 对应一节课件。请保留 `llm_core.py`、`app_core.py` 和实验脚本在同一目录；它们分别提供语言模型组件和本地应用测试组件。可以从任意工作目录运行。

```powershell
python lab_11_3.py
```

如终端显示中文或 emoji 编码异常，可在当前 PowerShell 会话设置 `$env:PYTHONUTF8='1'` 后再运行。正文里的 Python 小代码块均可独立执行；完整训练和边界测试在配套脚本中，流程伪代码标为 `text`。

- 生成及本轮逐节复核日期：2026-09-17。
- 已测环境：Python 3.11.15、NumPy 1.23.5、PyTorch 2.13.0+cpu、Matplotlib 3.7.2。
- 13 个实验脚本、16 段正文 Python 代码均重新运行通过；15 个 Python 文件（含 2 个共用模块）通过语法检查。13.1 每次独立重训一个小基座，再进行 SFT，不依赖之前运行留下的权重。
- 所有数据均为教学用人工数据；不读取个人笔记、不下载语料或模型、不执行 API 调用。
- 5 幅图由相应脚本写入本目录 `figures/`；再次运行会更新这些教学图。
- 12.3 在临时目录保存一个可信的本地 checkpoint，实验结束后自动清理。
- 固定种子便于复核，但跨设备、版本、并行实现不承诺逐位相同。

## 作者实测结果

### 11.1–11.3：从文本接口到语言模型

BPE 在小型英文训练文本上学习 20 次合并。`lower newer` 从 11 个 UTF-8 字节压缩为 3 个 token；未覆盖的中文/emoji 仍能无损编码，但不一定压缩。空文本 round trip 也通过。这不意味着该 tokenizer 具备语义理解。

Tiny LM 有 19,136 参数。768 个可能语法句子中，使用 384/96/96 个不重复句子作为 train/validation/test，其余未使用。验证 NLL 从约 3.1240 降至最佳约 0.7570；测试 NLL 约 0.7504，PPL 约 2.1179，token accuracy 约 58.91%。训练集拟合的 unigram 在相同测试集上的 NLL 约 2.4777。

该语法的总体平均条件熵为 $\log768/9\approx0.7382$ nats/target。随机内容本来就无法完美预测，因此不能要求 token accuracy 达到 100%。本轮补充推导总体最优 token accuracy 为 $(4+4/4+1/3)/9=16/27\approx59.26\%$，并验证 19,136 参数账本。理论总体参考不是每个有限测试估计的硬下界。

### 12.1–12.3：数据、预算与训练状态

四条人工数据记录依次经过许可标记过滤、规范化 exact dedup 和已知 benchmark 排除后，数量为 4→3→2→1。Near-duplicate Jaccard 示例为 0.75。这只是对指定规则的测试，不是实际网络语料质量认证。

Scaling 图使用**假设公式**而非训练实测：归一化预算 $ND=100$ 时解析最优点为 $N\approx6.667,D=15$，损失约 2.5492；两端配置示例损失为 3.3 与 4.2。不要把单位理解为某个前沿模型的参数/数据量。

12.3 的完整 batch 与正确加权 microbatch 梯度一致，错误的均值平均被检测。保存/恢复模型、AdamW、global RNG 和 sampler RNG 后，带 dropout 的下一次更新逐位相同。本轮进一步验证了变长 masked sequence 的梯度及 AdamW 更新、optimizer moments/step 重放，并检测省略 moments 后的更新差异。rank 平均只在 CPU 中模拟归约数学，不是运行分布式作业；同样没有运行 CUDA AMP。

### 13.1：保留失败与遗忘证据

Response-only SFT 的验证 NLL 从约 3.6310 降到 0.1653。测试 response NLL 约 0.2029，token accuracy 93.33%，自由生成整段 exact match 为 2/3。

失败例：`describe green dog` 生成了 `the green cat .`。原语法验证 NLL 从 0.7570 升至 1.9093。这同时展示了适配收益、未完全学会的组合泛化，以及原任务能力保留问题。三条测试数据太少，不能据此给出真实应用成功率。

### 13.2–13.4：局部机制验证

LoRA 在 8×6 的冻结权重上训练 28 个低秩参数，拟合已知 rank-2 更新，MSE 从约 0.02283 降到 $2.22\times10^{-18}$。目标刻意位于可表示的低秩集合中；这个结果不能证明真实模型的任意微调都可用 rank 2 完成。

DPO 离散候选实验把两个 prompt 的 preferred-response 概率从各自 1/3 提升到约 0.9327 与 0.9305，最终偏好 loss 约 0.1904。它是两个 tabular policies 的数学测试，不是聊天模型偏好评测。本轮另接入真正的 TinyLM policy/reference：初始相同模型产生 log(2) loss，完整参数梯度匹配链式法则，一小步更新提高指定 pair 的相对 margin，参考参数不变。这里只验证完整 decoder 的梯度，没有宣称完成大模型偏好训练。

Top-p 例子把 $[0.5,0.3,0.15,0.05]$ 在阈值 0.7 下变为 $[0.625,0.375,0,0]$。两步树上 greedy 的整段概率为 0.30，width-2 beam 找到 0.396，说明局部最优不等于整段最优。解码函数修复了先除极小温度可能造成溢出的计算顺序，使用先中心化的 float64 计算；增加稳定 tie 与 top-p=1 的明确约定。

### 14.1–14.3：应用边界而非模型能力

六个错误输出 fixture 被拒绝；合法 schema 下的“999 days”仍可通过结构验证，证明需要独立事实/grounding 检查。

六个开发问题上，TF-IDF 的 Recall@1、Recall@3、MRR 都为 4/6；加手写同义词后为 6/6。规则使用了这套 fixture 的信息，因此不是独立测试集上的语义检索提升证据。没有运行 embedding 模型、cross-encoder reranker 或真实生成模型。本轮保留一个真实负对照：`book loans quantum superconductivity` 的未知词被忽略后仍命中 loans，旧提取器错误回答“14 days”。新增 intent registry 只为已声明的人工问题类型提供保守拒答，不冒充通用语义理解。检索结果和索引/来源快照之间的可变对象也已隔离。

工具控制器在“提交成功但响应丢失”的模拟超时后安全重试，同一操作重放后副作用计数仍为 1。审批、权限、错误参数、预算和恶意提案测试通过。本轮新增 actor 隔离、结果 call ID、缓存快照和 goal predicate 校验。没有目标检查时，队列运行结束返回 `operations_completed`；显式目标检查通过才返回 `completed`，避免空队列被误认为任务成功。跨 actor 的独立授权操作会各自计数，同一 actor 的重试不会重复计数。所有副作用只在内存里模拟，没有外部预约或文件/网络修改。
