## 如何运行

每个 `lab_章_节.py` 对应一节课件，可以从任意工作目录运行。脚本在正文实验基础上补充数值、梯度和边界条件校验。正文中的 Python 代码块按同一节内的先后顺序执行；仅用于说明流程的伪代码已标为 `text`，不应直接当作完整程序运行。

需要安装 NumPy、PyTorch（CPU 版即可）与 Matplotlib。在 PowerShell 中，例如：

```powershell
python lab_05_4.py
```

也可以在编辑器中选择同一个 Python 环境，再运行文件。无需为这些例子配置 GPU 或下载数据。

- 已测环境：Python 3.11.15、NumPy 1.23.5、PyTorch 2.13.0+cpu、Matplotlib 3.7.2。
- 本轮复核日期：2026-09-16。
- 20 个配套脚本全部重新执行通过；正文 25 个可执行 Python 代码块也按节、按顺序运行通过。包含梯度、数值等价、形状、状态恢复和边界条件等断言。
- 大多数脚本打印结果；02.4、04.3、05.4、06.2 同时把图保存到本目录的 `figures/`。
- 01.4 使用临时 checkpoint 演示保存/恢复，示例结束后自动清理临时目录。
- 脚本使用固定种子，但跨设备、版本和运算实现不保证每个末位小数完全一致。

不要把断言验证、训练集拟合成功和真实任务泛化混为一谈。以下是作者执行教材实验的结果，不是对学习者掌握程度的认证。

## 实测结果如何解读

01.4 的验证 MSE 从约 3.787 降至约 0.0094，最佳 checkpoint 来自 epoch 21，约为 0.0093。恢复后重放下一 epoch 的结果通过一致性检查；这验证本例保存的模型、优化器和相关随机状态足以恢复本例训练，不代表任意训练管线都已自动可复现。回归数据本身有噪声，学习到的参数接近生成参数但不会完全相同。

02.4 的 1、3、15 次多项式验证 MSE 约为 0.2222、0.0318、0.0877。15 次模型训练误差更低，但本次验证结果比 3 次模型差。这支持该设置下的过拟合解释，不代表所有高容量模型都会更差。新增重复训练集实验的平均平方偏差约为 0.003765、方差约为 0.004550，并验证经验分解恒等式；新观测的噪声方差设为 0.0225，应与对无噪声信号的预测误差分开解释。

04.1 的 SGD、Momentum、Adam、无衰减 AdamW 验证 MSE 分别约为 0.1341、0.1206、0.1409、0.1409。学习率只是教学设置，没有进行同预算调参搜索。Adam 与无衰减 AdamW 的一致性是预期结果。新增逐步校验检查给定梯度序列下的参数与优化器状态，避免只用一次训练曲线反推更新公式。

04.2 的 ridge 实验中，正则化强度 0、0.01、0.1、1、10 对应验证 MSE 约为 4.938、4.563、3.192、3.238、5.121。本例中适量正则化有帮助，过强也会变差；不能把它理解成正则化越大越好。

04.3 验证：标量二次损失在学习率 2 时保持 4.5 并振荡，2.2 时增长。线性回归示例中学习率 0.05 的验证 MSE 约 0.0105，学习率 2 的结果约为 $1.62\times10^{10}$，是刻意展示的发散现象。按正文的索引与端点约定，六次更新使用的 warmup/cosine 学习率为 `[0.05, 0.1, 0.1, 0.0775, 0.0325, 0.01]`；两次相邻峰值来自这一具体约定。

05.4 的 MLP、CNN、CNN+BatchNorm 都达到 100% 验证准确率。以验证交叉熵选出的 MLP 在 96 个测试样本上也全对。任务很容易，结果主要证明管线正常，不能证明 MLP 普遍优于 CNN，也没有显示 BatchNorm 的必要性。CNN 使用约 1,300 个参数，MLP 使用 8,290 个；参数效率是另一个值得比较的维度。选中模型的常规测试交叉熵约为 0.00303，噪声偏移测试约为 0.01196，两者准确率均为 100%；这里只改变合成噪声，不是未见几何结构或自然图像上的泛化验证。

06.2 的 30 步标量梯度与 $a^{30}$ 在数值精度内吻合：$a=0.8,1,1.2$ 时约为 0.001238、1、237.376，分别展示消失、保持和爆炸。小型首位记忆任务本次验证准确率为 100%，不能据此给 RNN/LSTM 做普遍性能排名；更长序列、更多种子和更困难任务应作为后续实验。

06.3 的微型 token 分类实验只报告训练准确率 100%，用于检验查表、掩码和分类头连接，不是持出集上的语言理解能力证据。
