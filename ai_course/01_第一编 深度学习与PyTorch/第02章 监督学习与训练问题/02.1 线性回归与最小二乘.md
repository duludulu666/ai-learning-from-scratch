## 1. Motivation: learn how features contribute to a prediction

Suppose a continuous target depends approximately on several measured features. Begin with one contribution per feature and a constant offset:

$$
\hat y_i=\mathbf{x}_i^{\mathsf T}\mathbf{w}+b.
$$

Here $i$ indexes examples, $\mathbf{x}_i\in\mathbb{R}^{D}$ contains features, $\mathbf{w}\in\mathbb{R}^{D}$ contains learned weights, $b$ is a scalar bias, and $\hat y_i$ is the prediction. We reserve $y_i$ for the observed target.

“Linear” describes dependence on the chosen features. Polynomial features such as $x^2$ can still be used in a model linear in its parameters.

## 2. Why square the errors?

Let $e_i=\hat y_i-y_i$. Summing signed errors allows overprediction and underprediction to cancel. Absolute error avoids cancellation but has a corner at zero. Squared error is smooth and penalizes larger residuals more strongly.

Average the squared errors so that changing dataset size does not automatically multiply the objective. Include a convenient factor of $1/2$:

$$
L(\mathbf{w},b)=\frac{1}{2N}\sum_{i=1}^{N}e_i^2.
$$

This is half of the usual mean squared error. Its minimizers match MSE, but its gradients are half as large. Loss conventions must match when checking implementations.

## 3. A probability explanation: Gaussian observation noise

Suppose the target equals the prediction plus independent zero-mean Gaussian noise with fixed variance $\sigma^2$. A Gaussian assigns higher probability to small residuals:

$$
p(y_i\mid\mathbf{x}_i;\mathbf{w},b)
=\frac{1}{\sqrt{2\pi\sigma^2}}
 \exp\left(-\frac{e_i^2}{2\sigma^2}\right).
$$

Independence makes the dataset likelihood a product. Taking the negative logarithm turns that product into a sum:

$$
-\log p(\mathbf{y}\mid\mathbf{X})
=\frac{N}{2}\log(2\pi\sigma^2)
 +\frac{1}{2\sigma^2}\sum_i e_i^2.
$$

When $\sigma^2$ is fixed, the first term does not depend on the weights and the positive scale does not change the minimizer. Maximizing this likelihood therefore gives least squares.

This derivation explains an assumption, not a universal truth about real data. Outliers, unequal noise variances, and heavy tails can make other losses more appropriate.

## 4. Derive one parameter gradient through the residual

For one sample $\ell_i=e_i^2/2$, the change in loss with prediction is

$$
\frac{\partial\ell_i}{\partial\hat y_i}
=\frac{\partial\ell_i}{\partial e_i}
 \frac{\partial e_i}{\partial\hat y_i}
=e_i\cdot1=e_i.
$$

Changing $w_j$ changes $\hat y_i$ with slope $x_{ij}$. The chain rule therefore gives

$$
\frac{\partial\ell_i}{\partial w_j}=e_ix_{ij},
\qquad
\frac{\partial\ell_i}{\partial b}=e_i.
$$

Average contributions over examples:

$$
\frac{\partial L}{\partial w_j}
=\frac{1}{N}\sum_i e_ix_{ij},
\qquad
\frac{\partial L}{\partial b}
=\frac{1}{N}\sum_i e_i.
$$

A negative residual means underprediction. If the corresponding feature is positive, its weight gradient is negative; subtracting that gradient increases the weight and raises the prediction locally. Chapter 04 explains the necessary step-size conditions.

## 5. Batch form and the least-squares reference solution

Put examples into $\mathbf{X}\in\mathbb{R}^{N\times D}$ and targets into $\mathbf{y}\in\mathbb{R}^{N}$. Then

$$
\mathbf{e}=\mathbf{X}\mathbf{w}+b\mathbf{1}-\mathbf{y},
\quad
\nabla_{\mathbf{w}}L=\frac{\mathbf{X}^{\mathsf T}\mathbf{e}}{N},
\quad
\frac{\partial L}{\partial b}=\frac{\mathbf{1}^{\mathsf T}\mathbf{e}}{N}.
$$

The transpose sums residual contributions across samples, leaving one gradient per feature.

To include the bias in one matrix, append a column of ones to form $\mathbf{A}=[\mathbf{X}\ \mathbf{1}]$ and define $\boldsymbol{\theta}=[\mathbf{w}^{\mathsf T}\ b]^{\mathsf T}$. At an optimum,

$$
\mathbf{A}^{\mathsf T}(\mathbf{A}\boldsymbol{\theta}-\mathbf{y})=\mathbf{0}.
$$

These are the normal equations. If columns are independent, an inverse expression exists, but explicitly computing that inverse is numerically undesirable. Use `np.linalg.lstsq`, which also handles rank deficiency more sensibly.

Why does setting the gradient to zero solve this particular problem? Its Hessian is $\mathbf{A}^{\mathsf T}\mathbf{A}/N$. For any perturbation $\mathbf{v}$,

$$
\mathbf{v}^{\mathsf T}\frac{\mathbf{A}^{\mathsf T}\mathbf{A}}{N}\mathbf{v}
=\frac{\|\mathbf{A}\mathbf{v}\|_2^2}{N}\geq0.
$$

The squared-error objective is convex, so a stationary solution is a global minimum. If columns are independent, this quantity is positive for every nonzero $\mathbf{v}$ and the parameter solution is unique. With duplicated columns, adding a vector in the null space changes weights without changing predictions. `lstsq` returns a minimum-norm solution among least-squares minimizers.

The residual at a least-squares solution is orthogonal to every column of $\mathbf{A}$. Geometrically, the fitted target is the projection onto the space spanned by those columns.

### A two-example gradient calculation

Let $x=[1,2]$, $y=[3,5]$, and start with $w=b=0$. Predictions are $[0,0]$, residuals are $[-3,-5]$, and the half-MSE is $(9+25)/4=8.5$. The gradients are

$$
\frac{\partial L}{\partial w}=\frac{-3(1)-5(2)}2=-6.5,
\qquad
\frac{\partial L}{\partial b}=\frac{-3-5}2=-4.
$$

At learning rate 0.1, update both using these **old-parameter** gradients: $w'=0.65,b'=0.4$. Predictions become $[1.05,1.70]$ and half-MSE becomes $3.673125$. Updating the bias using residuals recomputed after only the weight update would be a different update rule.

## 6. Runnable experiment: manual gradient, autograd, and a solver

```python
import numpy as np
import torch

rng = np.random.default_rng(2)
X = rng.normal(size=(128, 3))
truth = np.array([2., -1., 0.5])
y = X @ truth + 0.7 + rng.normal(scale=0.1, size=128)

w = rng.normal(size=3)
b = 0.2
error = X @ w + b - y
dw = X.T @ error / len(X)
db = error.mean()

xt, yt = torch.tensor(X), torch.tensor(y)
wt = torch.tensor(w, requires_grad=True)
bt = torch.tensor(b, dtype=torch.float64, requires_grad=True)
loss = 0.5 * (xt @ wt + bt - yt).square().mean()
loss.backward()
np.testing.assert_allclose(dw, wt.grad.numpy())
np.testing.assert_allclose(db, bt.grad.numpy())

w, b = np.zeros(3), 0.0
for _ in range(400):
    error = X @ w + b - y
    w -= 0.1 * (X.T @ error / len(X))
    b -= 0.1 * error.mean()

A = np.column_stack([X, np.ones(len(X))])
reference, *_ = np.linalg.lstsq(A, y, rcond=None)
np.testing.assert_allclose(np.r_[w, b], reference, atol=1e-8)
print("learned:", np.r_[w, b])
print("generating:", np.r_[truth, 0.7])
```

The optimizer should match the least-squares solution more closely than it matches the generating parameters: the finite dataset contains noise.

## 7. Controlled experiments and mistakes

Multiply one feature by 100, without changing the information it represents. Refit the exact solver and compare gradient descent with a fixed learning rate. The ideal fit is still possible, but the curvature and optimization behavior change. Fit scaling statistics using training data only.

Add a large target outlier and compare how much the fitted coefficients move. Squared loss gives that observation a large gradient.

A low training loss does not establish causal relationships between features and targets. Correlated features also make individual coefficients hard to interpret.
