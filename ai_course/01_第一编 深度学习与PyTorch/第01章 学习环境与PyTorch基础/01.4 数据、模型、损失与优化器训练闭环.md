# 01.4 A Complete, Reproducible PyTorch Training Loop

> Prerequisites: 01.1–01.3. Goal: run a complete experiment whose data, losses, and saved results have clear meanings.

## 1. Start with the responsibilities

A training program answers six questions: where examples come from, how they are batched, how predictions are computed, how error is measured, how gradients are calculated, and how parameters are changed.

A `Dataset` provides individual examples. A `DataLoader` batches them. An `nn.Module` registers parameters and defines forward computation. A loss maps predictions and targets to a scalar. Autograd computes derivatives. An optimizer performs updates.

An **epoch** means one pass over the training examples; an **update** means one optimizer step. If batch size changes, equal epoch counts do not imply equal update counts.

## 2. Environment and experiment records

Use one interpreter with compatible NumPy, PyTorch, and Matplotlib installations. Record Python and library versions, the device, seed, split, batch size, optimizer settings, and number of updates. A notebook kernel must use the intended interpreter.

The examples in this part use small CPU-friendly datasets and `num_workers=0`. This also avoids Windows multiprocessing setup issues in notebooks. A GPU is optional.

Use a project environment and version control for your own experiments. Keep data-generation settings and model settings visible rather than relying on notebook cells executed in an unknown order.

## 3. Define one prediction problem with explicit shapes

We generate $N$ examples with $D=4$ features. Targets come from a known affine function plus noise:

$$
y_i=\mathbf{x}_i^{\mathsf T}\mathbf{w}^{\ast}+b^{\ast}+\epsilon_i.
$$

Here $\mathbf{w}^{\ast}$ and $b^{\ast}$ generate data, while the model learns its own parameters. Noise $\epsilon_i$ prevents perfect prediction of unseen observations.

Our model outputs shape `(B, 1)`, so targets also use `(B, 1)`. The mean squared error is

$$
L_B=\frac{1}{B}\sum_{i=1}^{B}(\hat y_i-y_i)^2.
$$

Unlike the half-squared loss in some derivations, this version has no factor $1/2$. Both are valid; the gradient scales differ.

## 4. Train, validate, and calculate the mean correctly

Training updates parameters. Validation measures the current model on held-out examples without updates. Validation influences model selection, so it is distinct from a final test.

To aggregate batch means with different batch sizes, weight each mean by its sample count:

$$
L_{\mathrm{epoch}}
=\frac{\sum_{\text{batches }B}|B|L_B}
       {\sum_{\text{batches }B}|B|}.
$$

For batches of 3 and 1 examples with mean losses 2 and 10, the example-weighted mean is $(3\cdot2+1\cdot10)/4=4$. The unweighted mean of batch means is 6, giving the one-example batch the same influence as the three-example batch.

Here each example has exactly one scalar target. For variable-length sequences, use the intended number of valid target tokens instead; section 06.1 develops that distinction.

Adding batch means and dividing by the number of batches overweights a short final batch. Also, the online training loss comes from a changing model across updates. For a fair train/validation comparison, evaluate both splits at the same final checkpoint in evaluation mode.

## 5. Runnable experiment, including checkpoint restoration

The block below is standalone. The temporary checkpoint is automatically removed after the demonstration; copy it to your own experiment directory when you want to retain a model.

```python
import copy
import random
import tempfile
from pathlib import Path

import numpy as np
import torch
from torch import nn
from torch.utils.data import TensorDataset, DataLoader

random.seed(7)
np.random.seed(7)
torch.manual_seed(7)
torch.set_num_threads(1)

X = torch.randn(320, 4)
truth = torch.tensor([[2.], [-1.], [0.5], [3.]])
y = X @ truth + 0.7 + 0.1 * torch.randn(320, 1)
split = torch.randperm(len(X))
train_idx, val_idx = split[:240], split[240:]

train_set = TensorDataset(X[train_idx], y[train_idx])
val_set = TensorDataset(X[val_idx], y[val_idx])
shuffle_rng = torch.Generator().manual_seed(11)
train_loader = DataLoader(train_set, batch_size=32, shuffle=True,
                          generator=shuffle_rng, num_workers=0)
train_eval_loader = DataLoader(train_set, batch_size=64)
val_loader = DataLoader(val_set, batch_size=64)

model = nn.Linear(4, 1)
optimizer = torch.optim.SGD(model.parameters(), lr=0.05)
criterion = nn.MSELoss()

@torch.no_grad()
def evaluate(loader):
    model.eval()
    loss_sum, count = 0.0, 0
    for inputs, targets in loader:
        predictions = model(inputs)
        assert predictions.shape == targets.shape
        loss_sum += criterion(predictions, targets).item() * len(inputs)
        count += len(inputs)
    return loss_sum / count

history = []
best_val, best_state = float("inf"), None
for epoch in range(30):
    model.train()
    for inputs, targets in train_loader:
        optimizer.zero_grad(set_to_none=True)
        predictions = model(inputs)
        loss = criterion(predictions, targets)
        loss.backward()
        optimizer.step()

    train_loss, val_loss = evaluate(train_eval_loader), evaluate(val_loader)
    history.append((train_loss, val_loss))
    if val_loss < best_val:
        best_val = val_loss
        best_state = {
            "model": copy.deepcopy(model.state_dict()),
            "optimizer": copy.deepcopy(optimizer.state_dict()),
            "epoch": epoch,
            "torch_rng": torch.get_rng_state(),
            "loader_rng": shuffle_rng.get_state(),
        }

with tempfile.TemporaryDirectory() as directory:
    path = Path(directory) / "checkpoint.pt"
    torch.save(best_state, path)
    saved = torch.load(path, weights_only=True)
    model.load_state_dict(saved["model"])
    optimizer.load_state_dict(saved["optimizer"])
    torch.set_rng_state(saved["torch_rng"])
    shuffle_rng.set_state(saved["loader_rng"])
    print("restored epoch:", saved["epoch"], "validation MSE:", evaluate(val_loader))

print("first/final evaluation losses:", history[0], history[-1])
print("learned weights:", model.weight.detach())
assert history[-1][1] < history[0][1]
```

The learned weights should approach the generating weights. Validation loss should fall substantially, but noise prevents exact recovery. A single seed is a reproducibility aid, not evidence that every split behaves identically.

Why `deepcopy`? A plain state dictionary can reference tensors that training continues to modify. A best-checkpoint snapshot must preserve the values from that moment. After restoring the model, evaluate it again and compare against the saved best validation value; successfully reading a file alone does not verify restoration.

For exact continuation of a larger experiment, also restore any scheduler, mixed-precision scaler, Python/NumPy random state, sampler state, and distributed settings that affect future work. The minimal example only needs its PyTorch and loader states. Restoring an epoch-end checkpoint must resume at `saved_epoch + 1`, not repeat the saved epoch. The companion script replays the next epoch twice from the same restored snapshot and checks the batch order, losses, parameters, and random state match.

## 6. How to inspect a failed run

First print one batch and target distribution. Then assert shapes and finite values. Try fitting a tiny subset. Inspect loss reduction, gradients, learning rate, and model modes before increasing model size.

A model that cannot fit a few clean examples often has an implementation or optimization issue. A model that fits training well but fails on validation needs generalization or data-distribution investigation.
