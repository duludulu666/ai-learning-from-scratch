## 1. Motivation: a compact language for repeated calculations

A linear neuron combines several features into one score. A layer repeats this computation with different weights. Linear algebra gives us a way to describe the entire layer while preserving which inputs influence which outputs.

We use column vectors in single-sample mathematics, and store samples in rows for batched code. These are compatible conventions; the transpose connects them.

## 2. From weighted sum to inner product

For $D$ input features, let $\mathbf{x},\mathbf{w}\in\mathbb{R}^{D}$ and $b\in\mathbb{R}$. Each $w_j$ says how changing feature $x_j$ affects the score when other features are fixed.

Adding the weighted contributions gives

$$
y=\sum_{j=1}^{D}w_jx_j+b
=\mathbf{w}^{\mathsf T}\mathbf{x}+b.
$$

For $\mathbf{x}=[1,2]^{\mathsf T}$, $\mathbf{w}=[3,-1]^{\mathsf T}$, and $b=0.5$, the score is $1.5$. A negative weight does not make the feature unimportant; it reverses the direction of its contribution.

The inner product measures alignment **and magnitude**. Cosine similarity removes magnitudes by dividing by both norms; it is undefined for a zero vector without an explicit convention.

## 3. From one neuron to a matrix

Stack $O$ neurons' weight vectors into the rows of $\mathbf{W}\in\mathbb{R}^{O\times D}$. Stack their biases into $\mathbf{b}\in\mathbb{R}^{O}$. Then

$$
\mathbf{y}=\mathbf{W}\mathbf{x}+\mathbf{b}.
$$

The term $\mathbf{W}\mathbf{x}$ is linear: it preserves addition and scalar multiplication. Adding a nonzero bias makes the map **affine**. Deep learning often calls the entire affine operation a “linear layer.”

For a batch $\mathbf{X}\in\mathbb{R}^{B\times D}$, row $i$ contains $\mathbf{x}_i^{\mathsf T}$. Transpose the single-sample equation to obtain a row output, then stack rows:

$$
\mathbf{Y}=\mathbf{X}\mathbf{W}^{\mathsf T}+\mathbf{b},
\qquad
\mathbf{Y}\in\mathbb{R}^{B\times O}.
$$

The shorthand $+\mathbf{b}$ means broadcasting over rows. PyTorch stores `nn.Linear(D, O).weight` with shape `(O, D)`.

## 4. Composition explains why depth needs nonlinearity

Let the first layer map $D$ features to $H$ hidden features, and the second map $H$ to $O$ outputs. Substitute the first affine expression into the second:

$$
\begin{aligned}
\mathbf{y}
&=\mathbf{W}_2(\mathbf{W}_1\mathbf{x}+\mathbf{b}_1)+\mathbf{b}_2\\
&=(\mathbf{W}_2\mathbf{W}_1)\mathbf{x}
 +(\mathbf{W}_2\mathbf{b}_1+\mathbf{b}_2).
\end{aligned}
$$

The effective weight still has shape $O\times D$. Without an activation between the layers, the composition is still affine. A nonlinear activation makes the second layer depend on a transformed representation that cannot generally be absorbed into one fixed matrix.

## 5. Norms measure size; squared norms make useful losses

The Euclidean norm should reflect the length of a vector. Pythagoras gives

$$
\|\mathbf{x}\|_2=\sqrt{\sum_j x_j^2}.
$$

For $\mathbf{x}=[3,4]^{\mathsf T}$, the norm is $5$. If $\mathbf{e}$ is a prediction error, $\|\mathbf{e}\|_2^2$ adds squared errors across coordinates. Squaring removes sign cancellation.

For a matrix, the Frobenius norm sums over all entries:

$$
\|\mathbf{W}\|_F^2=\sum_i\sum_j W_{ij}^2.
$$

This is the matrix analogue used in an L2 weight penalty. Specify whether a loss sums or averages coordinates; the gradient scale changes.

## 6. Outer products create weight gradients

An inner product maps two vectors to one scalar. An outer product maps $\mathbf{u}\in\mathbb{R}^{O}$ and $\mathbf{x}\in\mathbb{R}^{D}$ to an $O\times D$ matrix:

$$
(\mathbf{u}\mathbf{x}^{\mathsf T})_{ij}=u_ix_j.
$$

Why does this appear in backpropagation? Changing $W_{ij}$ changes output $y_i$ by $x_j$ times that change. If the loss sensitivity to $y_i$ is $u_i$, the combined sensitivity is $u_ix_j$. Chapter 03 derives every step.

## 7. Jacobians describe how a vector function changes

For $\mathbf{f}:\mathbb{R}^{D}\to\mathbb{R}^{O}$, one derivative is insufficient because every output may depend on every input. Put these derivatives in a matrix:

$$
J_{ij}=\frac{\partial f_i}{\partial x_j},
\qquad
\Delta\mathbf{f}\approx\mathbf{J}\Delta\mathbf{x}.
$$

For $\mathbf{f}(\mathbf{x})=\mathbf{W}\mathbf{x}+\mathbf{b}$, $\mathbf{J}=\mathbf{W}$.

If a scalar loss has output gradient $\mathbf{g}_{y}\in\mathbb{R}^{O}$, the chain rule sums all output paths:

$$
\frac{\partial L}{\partial x_j}
=\sum_i\frac{\partial L}{\partial y_i}
       \frac{\partial y_i}{\partial x_j},
\qquad
\mathbf{g}_{x}=\mathbf{J}^{\mathsf T}\mathbf{g}_{y}.
$$

For a concrete example, let

$$
\mathbf{W}=\begin{bmatrix}2&-1\\3&4\end{bmatrix},
\qquad
\mathbf{g}_y=\begin{bmatrix}5\\-2\end{bmatrix}.
$$

Changing $x_1$ influences both outputs, so its gradient is $2(5)+3(-2)=4$. Changing $x_2$ gives $(-1)(5)+4(-2)=-13$. Stacking these sums gives $\mathbf{W}^{\mathsf T}\mathbf{g}_y=(4,-13)^{\mathsf T}$. For a tiny change $\Delta\mathbf{x}=(0.001,0)^{\mathsf T}$, the first-order loss change is approximately $0.004$. The gradient is a sensitivity, not the new parameter value.

Backpropagation computes these products efficiently, usually without materializing a full Jacobian. 中文提示：转置不是为了“凑形状”随手加的，而是对所有输出路径求和后得到的索引结构。

## 8. Runnable experiment: three equivalent views

```python
import numpy as np
import torch
from torch import nn

X = np.array([[1., 2.], [3., -1.]], dtype=np.float64)
W = np.array([[3., -1.], [2., 4.], [-1., 0.]], dtype=np.float64)
b = np.array([0.5, 0., 1.], dtype=np.float64)
Y = X @ W.T + b

layer = nn.Linear(2, 3).double()
with torch.no_grad():
    layer.weight.copy_(torch.from_numpy(W))
    layer.bias.copy_(torch.from_numpy(b))
np.testing.assert_allclose(layer(torch.from_numpy(X)).detach().numpy(), Y)

x = torch.tensor([1., 2.], dtype=torch.float64, requires_grad=True)
upstream = torch.tensor([1., -2., 0.5], dtype=torch.float64)
loss = (layer(x) * upstream).sum()
loss.backward()

torch.testing.assert_close(x.grad, layer.weight.T @ upstream)
torch.testing.assert_close(layer.weight.grad, torch.outer(upstream, x.detach()))
print("outputs:\n", Y)
print("input gradient:", x.grad)
print("weight gradient shape:", layer.weight.grad.shape)

J = torch.autograd.functional.jacobian(layer, x.detach())
torch.testing.assert_close(J, layer.weight)
```

The experiment checks outputs, the transposed-Jacobian calculation, and the outer-product weight gradient. These are small enough to inspect entry by entry.

## 9. Common mistakes and exercises

A transpose exchanges axes; it does not reverse values within a row. The norm is not the sum of signed entries. A matrix product's inner dimensions must match, but its meaning still depends on axis labels.
