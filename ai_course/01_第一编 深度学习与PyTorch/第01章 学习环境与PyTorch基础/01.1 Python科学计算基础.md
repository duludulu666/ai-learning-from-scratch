> Prerequisite: basic Python lists, loops, and functions. Goal: describe what each axis means before writing an operation.

## 1. Motivation: compute many predictions at once

Suppose each example has four features. A Python list can hold one example, but training needs thousands of examples, each using the same calculation. An array stores these values in a regular arrangement and lets numerical libraries perform the repeated work efficiently.

A tensor's **shape** specifies the length of each axis. Shape alone does not tell you its meaning: `(32, 4)` might mean 32 samples with four features or a small grayscale image. Write the meaning next to the shape.

We will use $B$ for batch size and $D$ for features. A batch is $\mathbf{X}\in\mathbb{R}^{B\times D}$; entry $X_{ij}$ is feature $j$ of sample $i$. Indices in Python begin at zero.

## 2. Scalars, vectors, and matrices

A scalar has shape `()`, a one-dimensional array has shape `(D,)`, and a matrix has shape `(B, D)`. The comma in `(D,)` is Python tuple syntax.

A NumPy vector is neither explicitly a row nor a column. Transposing a one-dimensional array leaves its shape unchanged. To make a column use `x[:, None]`, producing `(D, 1)`; to make a row use `x[None, :]`, producing `(1, D)`.

A `dtype` describes how entries are represented. Use floating-point arrays for continuous calculations. `float32` is a common training dtype; `float64` is useful when checking numerical derivatives. Integer IDs and continuous features have different jobs.

## 3. Selecting entries and reducing axes

For `X.shape == (B, D)`:

| Expression | Shape | Meaning |
|---|---|---|
| `X[0]` | `(D,)` | First sample |
| `X[:1]` | `(1, D)` | A batch containing the first sample |
| `X[:, 0]` | `(B,)` | First feature across samples |
| `X.mean(axis=0)` | `(D,)` | Average feature vector |
| `X.mean(axis=1)` | `(B,)` | Average of each sample's features |
| `X.mean(axis=1, keepdims=True)` | `(B, 1)` | Same result with the reduced axis retained |

An axis passed to a reduction is the axis being collapsed. To center each sample around its own mean, subtract the `(B, 1)` result. To center each feature across samples, subtract the `(D,)` result. These are different transformations.

## 4. Broadcasting, derived from a concrete need

A linear layer adds the same bias to every sample. Copying the bias $B$ times would be wasteful. Broadcasting describes how to reuse it.

Compare shapes **from right to left**. Two axis lengths are compatible if they match or one is 1; a missing leading axis behaves as length 1.

For `(B, D) + (D,)`, the last dimensions match and the missing leading axis expands across $B$. For `(B, D) + (B, 1)`, the last axis of the second array expands across features.

A dangerous case is `(B, 1) - (B,)`. The second array behaves like `(1, B)`, so the result is `(B, B)`: every prediction is compared with every target. The code runs, but it computes the wrong loss. Match prediction and target shapes explicitly.

### A broadcast bug with actual values

Suppose the two correct predictions and labels are both $[1,3]$, but predictions are stored as a column and labels as a one-dimensional array:

$$
\begin{bmatrix}1\cr3\end{bmatrix}
-\begin{bmatrix}1&3\end{bmatrix}
=\begin{bmatrix}0&-2\cr2&0\end{bmatrix}.
$$

The intended residual is $[0,0]$ with MSE 0. The broadcasted matrix instead has MSE $(0+4+4+0)/4=2$. This bug changes the learning problem; it is not just an inconvenient shape. Choose either `(B,)` for both arrays or `(B,1)` for both.

## 5. Matrix multiplication from repeated inner products

For one sample, one neuron multiplies each feature by its weight and adds the results. For $O$ output neurons, let $\mathbf{W}\in\mathbb{R}^{O\times D}$ and $\mathbf{b}\in\mathbb{R}^{O}$.

The output for sample $i$, neuron $j$ is

$$
Y_{ij}=\sum_{k=1}^{D}X_{ik}W_{jk}+b_j.
$$

The sum removes feature index $k$ and leaves sample index $i$ and output index $j$. Therefore $\mathbf{Y}\in\mathbb{R}^{B\times O}$ and

$$
\mathbf{Y}=\mathbf{X}\mathbf{W}^{\mathsf T}+\mathbf{b}.
$$

`@` implements the sum of products. `*` multiplies entries element by element and does not perform that sum.

## 6. Reshape, transpose, and storage

`reshape` changes how entries are grouped; `transpose` changes which axis an index refers to. A reshape cannot replace a transpose just because both yield the same shape.

For `a = [[0,1,2],[3,4,5]]`, transposing produces rows `[0,3],[1,4],[2,5]`. Reshaping to `(3,2)` instead groups the original row-major order into `[0,1],[2,3],[4,5]`. Both outputs have shape `(3,2)`; only the transpose preserves the intended exchange of row and column roles.

Basic slices often share storage with the original array. Modifying a slice may modify the original. Use `copy()` when independent storage is required. A reshape may return a view or a copy; do not use it as a promise of independent storage.

## 7. Runnable experiment: loops, NumPy, and PyTorch

Run the whole block. It defines every variable and uses no external data.

```python
import numpy as np
import torch

rng = np.random.default_rng(7)
X = rng.normal(size=(8, 4)).astype(np.float64)
W = rng.normal(size=(3, 4)).astype(np.float64)
b = rng.normal(size=(3,)).astype(np.float64)

Y_loop = np.zeros((8, 3))
for i in range(8):
    for j in range(3):
        Y_loop[i, j] = sum(X[i, k] * W[j, k] for k in range(4)) + b[j]

Y_numpy = X @ W.T + b
Y_torch = torch.from_numpy(X) @ torch.from_numpy(W).T + torch.from_numpy(b)
np.testing.assert_allclose(Y_loop, Y_numpy)
np.testing.assert_allclose(Y_numpy, Y_torch.numpy())
print("output shape:", Y_numpy.shape)

sample_centered = X - X.mean(axis=1, keepdims=True)
np.testing.assert_allclose(sample_centered.mean(axis=1), 0, atol=1e-14)

prediction = np.arange(8.0).reshape(8, 1)
target = np.arange(8.0)
print("wrong residual:", (prediction - target).shape)
print("correct residual:", (prediction[:, 0] - target).shape)

a = np.arange(6).reshape(2, 3)
print("transpose:\n", a.T)
print("reshape:\n", a.reshape(3, 2))
```

You should see `(8, 3)` for the affine output, `(8, 8)` for the unintended pairwise residual, and different entries for transpose versus reshape. Numerical equality between the loop and vectorized versions verifies the operation's meaning; speed alone would not.

## 8. Common mistakes and debugging order

Before changing code, write the expected axes, print actual shapes, inspect dtype, then inspect a small numerical example. Do not fix a shape mismatch with arbitrary `reshape` until the sample and feature meanings are clear.

Vectorization improves execution by handing work to compiled numerical kernels. It does not automatically reduce the mathematical complexity of matrix multiplication.
