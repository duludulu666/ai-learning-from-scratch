## 1. Motivation: order can change meaning

A bag containing the words “dog,” “bites,” and “person” loses the difference between “dog bites person” and “person bites dog.” Likewise, the same measurements in reverse order may describe a different temporal process.

An ordinary image classifier produces one prediction per image. A sequence model must specify how observations at different positions interact. Independent **sequences** can still form independent training samples; the need for sequence modeling does not mean every dataset assumption disappears.

Let $B$ be batch size, $T$ sequence length, and $D$ features per position. A common tensor layout is

$$
\mathbf{X}\in\mathbb{R}^{B\times T\times D}.
$$

A video needs additional channel and spatial axes unless each frame has already been encoded into features.

## 2. Three prediction arrangements

In many-to-one prediction, a whole sequence produces one label, such as an utterance category. Many-to-many prediction produces an output at each position, such as a tag for every word. Forecasting or autoregressive prediction uses a prefix to predict the future.

The same shape can represent different tasks. Before selecting a network, state the input available for each target and whether future positions are allowed.

A bidirectional encoder can use both earlier and later positions for offline tagging. It would leak information if used unchanged for a next-step prediction that is supposed to know only the past.

## 3. Why the mean loses order

A simple sequence summary averages its vectors:

$$
\bar{\mathbf{x}}=\frac{1}{T}\sum_{t=1}^{T}\mathbf{x}_t.
$$

Reordering the terms leaves the sum unchanged. Therefore a classifier using only the mean cannot distinguish two sequences that contain the same vectors in different orders.

This is a representation limitation: training longer cannot recover information that the input summary discarded. It motivates recurrent state, positional features, temporal convolution, and eventually attention with positional information.

## 4. Autoregressive factorization follows the probability chain rule

For discrete observations $x_1,\ldots,x_T$, the chain rule of probability gives

$$
p(x_1,\ldots,x_T)
=p(x_1)\prod_{t=2}^{T}p(x_t\mid x_1,\ldots,x_{t-1}).
$$

This is a probability identity, not a neural-network invention. A model approximates each conditional distribution from the available prefix.

Taking a negative logarithm gives a sum of next-step losses:

$$
L=-\sum_{t=1}^{T}\log p_{\boldsymbol{\theta}}(x_t\mid x_{<t}),
$$

where $x_{<t}$ denotes earlier positions and the empty prefix can be represented by a beginning-of-sequence token. Later LLM chapters add tokenization, batching, and scaling; the causal objective starts here.

## 5. Align inputs and targets carefully

For a token sequence $[a,b,c,d]$, a simple training pair is:

```text
inputs:  [a, b, c]
targets: [b, c, d]
```

At input position $t$, predict the token at $t+1$. During training, use the true preceding tokens as inputs; this is teacher forcing. For a sequence of length $T$, the unpadded next-token objective has $T-1$ supervised positions, not $T$; adding BOS/EOS changes that bookkeeping and should be stated.

At generation time, the next input may be the model's own sampled output. Errors can change later contexts. Matching training loss does not by itself describe free-running generation behavior.

A `Linear` layer on a tensor $(B,T,D)$ transforms the last dimension independently. It does not mix positions just because a time axis is present.

## 6. Padding and masked loss

Sequences in a batch can have different lengths. Pad them to a common $T$, but remember which positions are real.

Let $m_{n,t}\in\{0,1\}$ indicate a valid target and let $\ell_{n,t}$ be its loss. Average over valid targets:

$$
L=\frac{\sum_{n,t}m_{n,t}\ell_{n,t}}
        {\sum_{n,t}m_{n,t}},
$$

assuming the denominator is positive. Dividing by $BT$ instead would make the loss scale depend on the amount of padding.

For valid lengths 4 and 2 with no BOS/EOS, there are $(4-1)+(2-1)=4$ next-token targets. If the first sequence's three losses are $[1,2,3]$ and the second has loss $[4]$, the valid-token mean is $10/4=2.5$. Padding both to three prediction slots and dividing by 6 would incorrectly give $10/6$.

Masking after an invalid operation is unsafe: `0 * NaN` is still NaN, and out-of-range padded class IDs can fail before multiplication occurs. The demonstration uses valid in-range PAD IDs and finite logits. For general masked classification, select valid logits/labels before cross-entropy, or use a documented ignore-index convention. An all-invalid batch has no mean target loss; reject or skip it deliberately.

A loss mask and an attention mask have different purposes. Ignoring a padded target does not automatically prevent the network from using padded or future inputs internally. Architecture or an internal mask must enforce the intended information boundary.

## 7. Runnable experiment: order, shifted targets, and valid-token averaging

```python
import torch
import torch.nn.functional as F
from torch import nn

torch.manual_seed(2)
sequences = torch.tensor([[[0.], [1.]], [[1.], [0.]]])
torch.testing.assert_close(sequences[0].mean(0), sequences[1].mean(0))
ordered_score = sequences[:, -1, 0] - sequences[:, 0, 0]
print("same mean, different order score:", ordered_score)

# Token 0 is padding; tokens 1–4 are actual observations.
tokens = torch.tensor([[1, 2, 3, 4], [2, 3, 0, 0]])
lengths = torch.tensor([4, 2])
inputs, targets = tokens[:, :-1], tokens[:, 1:]
valid = torch.arange(targets.shape[1])[None, :] < (lengths - 1)[:, None]
assert valid.sum().item() == 4

embedding = nn.Embedding(5, 4, padding_idx=0)
head = nn.Linear(4, 5)
logits = head(embedding(inputs))  # A position-wise baseline, no context mixing
per_token = F.cross_entropy(logits.reshape(-1, 5),
                            targets.reshape(-1), reduction="none").reshape_as(targets)
masked_loss = (per_token * valid).sum() / valid.sum()
indexed_loss = F.cross_entropy(logits[valid], targets[valid])
torch.testing.assert_close(masked_loss, indexed_loss)
masked_loss.backward()
torch.testing.assert_close(embedding.weight.grad[0], torch.zeros(4))

print("input/target/logit shapes:", inputs.shape, targets.shape, logits.shape)
print("valid targets:", targets[valid])
print("masked loss:", masked_loss.item())
```

The companion script verifies a safer indexed masked loss: it stays unchanged after appending padding or perturbing ignored logits, and rejects all-invalid masks. These checks validate the loss boundary, not the internal visibility of an RNN or attention model.

The baseline predicts from only the current token embedding. It cannot use a longer history. That limitation will motivate the recurrent model in 06.2.

## 8. Temporal splits and overlapping windows

If adjacent training windows overlap heavily with validation windows, they can share most observations or even target values. Split the underlying sequence or group before constructing windows, and consider a gap where needed.

For forecasting, preprocessing must also respect time: a feature computed using future observations may leak even when the network is causal.

Padding should not change the meaning of a final state. An RNN run through additional padding steps can update its state; use sequence lengths, packing, or select the last valid state deliberately.
