## 1. Combining sensors is an information-design decision

Suppose two inputs describe the same event: an image stream and a sound stream. One may be noisy, delayed, unavailable, or contradictory. More inputs do not automatically mean better predictions.

Fusion asks where information meets. Early fusion combines features before prediction. Late fusion combines predictions. Cross-modal attention allows one representation to read another. These choices differ in which interactions they can represent and how they behave when an input is missing.

Before choosing a mechanism, specify alignment: do the two inputs refer to the same example and time interval? A powerful fusion model trained on mismatched pairs can learn misleading correlations.

## 2. Early fusion: expose interactions to a shared network

For one example, let $\mathbf{x}\in\mathbb{R}^{d_x}$ and $\mathbf{z}\in\mathbb{R}^{d_z}$ be features. Concatenation creates

$$
\mathbf{h}=[\mathbf{x};\mathbf{z}]
\in\mathbb{R}^{d_x+d_z},
\qquad
\widehat y=f_\theta(\mathbf{h}).
$$

The semicolon denotes concatenation, not matrix multiplication. A nonlinear $f_\theta$ can learn interactions between the modalities. A purely linear layer on concatenated inputs remains additive and does not acquire nonlinear interaction capacity merely because the features came from two sensors.

Normalize feature scales using training-only statistics. If one branch has values around 1000 and another around 0.01, optimization can be poorly conditioned. Normalization helps scale; it does not fix mislabeled or time-misaligned data.

## 3. A truth-table counterexample explains interaction

Let each modality be one bit, $x,z\in\{0,1\}$, and the target be XOR: positive when they disagree. Neither input alone predicts the balanced target.

Consider additive late **logits** $s(x,z)=a(x)+b(z)$ with threshold zero. Perfect classification requires

$$
\begin{aligned}
a(0)+b(0)&<0,\cr
a(0)+b(1)&>0,\cr
a(1)+b(0)&>0,\cr
a(1)+b(1)&<0.
\end{aligned}
$$

Adding the two positive inequalities says $a(0)+a(1)+b(0)+b(1)>0$. Adding the two negative inequalities says the same quantity is below zero. Contradiction.

A nonlinear early-fusion network can solve XOR. This is a representational statement, not a claim that early fusion always generalizes better. A sophisticated late combiner that sees both branches and learns interactions may escape this particular limitation; then it is no longer the simple additive model proved insufficient here.

## 4. Late fusion: decide what is being combined

Let $\mathbf{p}^{(x)},\mathbf{p}^{(z)}\in\mathbb{R}^{C}$ be normalized class probabilities. A weighted mixture uses nonnegative weights summing to one:

$$
\mathbf{p}_{\mathrm{mix}}
=\lambda\mathbf{p}^{(x)}+(1-\lambda)\mathbf{p}^{(z)},
\qquad 0\leq\lambda\leq1.
$$

For positive-class probabilities 0.9 and 0.2 with $\lambda=0.6$, the result is $0.6(0.9)+0.4(0.2)=0.62$.

Probability averaging, logit averaging, and logit summation are three different rules. Let $\mathbf{p}^{(x)}=\mathrm{softmax}(\mathbf{s}^{(x)})$ and similarly for $z$, assuming positive class probabilities. Exponentiate a weighted logit sum:

$$
\mathrm{softmax}\!\left(\lambda\mathbf{s}^{(x)}+(1-\lambda)\mathbf{s}^{(z)}\right)_c
=
\frac{(p_c^{(x)})^\lambda(p_c^{(z)})^{1-\lambda}}
{\sum_j(p_j^{(x)})^\lambda(p_j^{(z)})^{1-\lambda}}.
$$

To derive this, write $\exp(s_c^{(x)})=Z_xp_c^{(x)}$, where $Z_x=\sum_j\exp(s_j^{(x)})$. The factors $Z_x^\lambda Z_z^{1-\lambda}$ are identical for every class, so they cancel during normalization.

Equal logit averaging therefore produces a normalized **geometric mean**. Logit summation instead gives

$$
\mathrm{softmax}\!\left(\mathbf{s}^{(x)}+\mathbf{s}^{(z)}\right)_c
=\frac{p_c^{(x)}p_c^{(z)}}{\sum_jp_j^{(x)}p_j^{(z)}}.
$$

For probabilities $(.9,.1)$ and $(.6,.4)$, equal probability mixing gives positive probability .75; equal logit averaging gives approximately .7861; logit summation gives $.54/(.54+.04)\approx.9310$. The lab checks all three. Summing versus averaging the same logits also changes temperature.

This product can become sharply confident. Interpreting it as a Bayesian posterior needs conditional-independence and prior accounting; multiplying two posteriors can double-count the prior. Neither mixture nor product is automatically calibrated.

## 5. Missing modalities require an explicit contract

Let $r_x,r_z\in\{0,1\}$ indicate availability and let $w_x,w_z>0$ be chosen reliability weights. Renormalize over available branches:

$$
\mathbf{p}=
\frac{r_xw_x\mathbf{p}^{(x)}+r_zw_z\mathbf{p}^{(z)}}
{r_xw_x+r_zw_z}.
$$

If only $x$ is available, this reduces to $\mathbf{p}^{(x)}$. If both are missing, the denominator is zero: return an explicit unavailable/abstain state or a separately justified prior policy. Do not divide by epsilon and present a zero vector as a valid prediction.

```python
import torch
prob = torch.tensor([[.9, .2], [.9, .2], [.9, .2]])
available = torch.tensor([[1., 1.], [1., 0.], [0., 1.]])
weights = available * torch.tensor([.6, .4])
assert (weights.sum(1) > 0).all()
fused = (weights * prob).sum(1) / weights.sum(1)
torch.testing.assert_close(fused, torch.tensor([.62, .9, .2]))
```

Availability is not reliability. An available microphone can be corrupted. Zero-filled features may look like genuine silence. A missingness indicator and training-time modality dropout can help the model learn missing-input behavior, but must be evaluated under realistic missingness patterns.

中文确认：缺失、低质量、互相矛盾是三种不同情况，不能都用“把某个输入填 0”来处理。

### A missing value is not necessarily the number zero

Multiplying an unavailable branch by weight zero does not sanitize a NaN: IEEE floating-point arithmetic gives $0\cdot\mathrm{NaN}=\mathrm{NaN}$. Select a finite placeholder **before** multiplication using the known availability mask.

The companion's fusion helper accepts NaNs only at explicitly unavailable positions, rejects nonfinite available probabilities, and rejects rows with no available modality. This tests the policy stated above instead of merely checking that an all-false mask has no true elements.

## 6. Cross-modal attention and gating

Cross-modal attention from 15.3 lets queries from one stream select evidence in another. It can model fine-grained associations such as a sound event aligning with a visual region or time. It still needs masks, timestamps, and appropriate training supervision.

A learned gate can produce $\lambda=\sigma(g_\phi(\mathbf{x},\mathbf{z},r_x,r_z))$, where $\sigma$ is sigmoid and $g_\phi$ is a scalar-output network. A gate can adapt weights to context, but can also learn a shortcut: always trust the easier branch on the training distribution.

Train and evaluate single-modality baselines, full fusion, missing-modality cases, corrupted inputs, and swapped pairing. If full fusion performs well but swapping one modality has no effect, investigate whether that modality contributes anything.

## 7. What the experiment establishes

The companion trains a nonlinear early model and an additive late-logit model on all four XOR inputs. It then verifies the availability-renormalization formula. This is a controlled capacity test, **not** a train/test generalization study.

The early model's success demonstrates a nonlinear interaction. The late model's failure matches the proof. It does not justify choosing early fusion for every real multimodal task.
