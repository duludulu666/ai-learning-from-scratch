## 1. Why one global image vector can be insufficient

A dual encoder answers “Do this image and this sentence match?” A question-answering model must often choose different evidence for different questions. “What color?” and “How many?” should not necessarily use the same image summary.

Cross-attention lets text states act as queries over visual tokens. The text stream asks; the image stream provides keys and values. This is the same operation from Chapter 07 with different input sources, not an entirely new type of differentiation.

We will compare three connectors: projection into prefix tokens, direct cross-attention, and learned-query compression. None is automatically the best architecture for every dataset and budget.

## 2. Start with the lengths that need not match

Let text hidden states be $\mathbf{H}\in\mathbb{R}^{B\times T\times D_t}$ and visual features be $\mathbf{Z}\in\mathbb{R}^{B\times N\times D_v}$. There are $T$ text positions and $N$ visual tokens; $D_t,D_v$ may differ.

For one head, choose query/key width $d_k$ and value width $d_v$. The row-vector projection matrices have shapes

$$
\mathbf{W}_Q\in\mathbb{R}^{D_t\times d_k},
\quad
\mathbf{W}_K\in\mathbb{R}^{D_v\times d_k},
\quad
\mathbf{W}_V\in\mathbb{R}^{D_v\times d_v}.
$$

Then $\mathbf{Q}=\mathbf{H}\mathbf{W}_Q$, $\mathbf{K}=\mathbf{Z}\mathbf{W}_K$, and $\mathbf{V}=\mathbf{Z}\mathbf{W}_V$. PyTorch Linear stores each corresponding weight transposed relative to this row-vector notation.

A query compares with every visual key:

$$
\mathbf{S}=\frac{\mathbf{Q}\mathbf{K}^{\mathsf T}}{\sqrt{d_k}},
\qquad
\mathbf{A}=\mathrm{softmax}_{N}(\mathbf{S}+\mathbf{M}),
\qquad
\mathbf{O}=\mathbf{A}\mathbf{V}.
$$

The transpose acts on the last two axes. Shapes are $\mathbf{S},\mathbf{A}:(B,T,N)$ and $\mathbf{O}:(B,T,d_v)$. Mask $\mathbf{M}$ adds zero for valid visual tokens and negative infinity for padding. Multi-head attention repeats this at several heads, concatenates outputs, and projects back to $D_t$ so a text residual can be added.

## 3. A hand read operation

Take one query, $d_k=1$, $\mathbf{Q}=[1]$, two keys $\mathbf{K}=[1,0]^{\mathsf T}$, and values $\mathbf{V}=[10,2]^{\mathsf T}$. Scores are $(1,0)$; weights are approximately $(0.7311,0.2689)$. The output is

$$
o=0.7311(10)+0.2689(2)\approx7.8488.
$$

If the second item is padding, mask it before softmax. Weights become $(1,0)$ and output becomes 10. Multiplying the final output by a mask cannot undo contamination that already entered the weighted sum.

If every visual position is masked, softmax has no valid distribution. Reject the example or provide an explicitly designed/trained null-modality token. Do not silently accept NaNs, and do not treat a zero vector as automatically equivalent to missing evidence.

## 4. How an answer loss trains the connector

Suppose downstream loss gives output gradient $\mathbf{G}_O$. Because $\mathbf{O}=\mathbf{A}\mathbf{V}$,

$$
\mathbf{G}_V=\mathbf{A}^{\mathsf T}\mathbf{G}_O,
\qquad
\mathbf{G}_A=\mathbf{G}_O\mathbf{V}^{\mathsf T}.
$$

The first equation distributes answer error to visual values. The second says how changing each attention weight would affect the answer.

For one attention row with weights $\mathbf{a}$ and upstream gradient $\mathbf{g}$, the softmax gradient is

$$
\mathbf{g}_s=\mathbf{a}\odot
\left(\mathbf{g}-(\mathbf{a}^{\mathsf T}\mathbf{g})\mathbf{1}\right).
$$

This subtracts the weighted mean because increasing one normalized probability affects the others. Continuing through the scaled dot products gives

$$
\mathbf{G}_Q=\frac{\mathbf{G}_S\mathbf{K}}{\sqrt{d_k}},
\qquad
\mathbf{G}_K=\frac{\mathbf{G}_S^{\mathsf T}\mathbf{Q}}{\sqrt{d_k}}.
$$

Thus loss can teach both what the question asks and which visual features are useful. If a pretrained visual encoder is frozen, its parameters do not update, but trainable projections still receive gradients.

Freezing model parameters and disabling autograd for a whole subgraph are different. A frozen language model may still need autograd to carry loss gradients back to a trainable visual prefix. Wrapping that entire language model forward in `no_grad()` would break the bridge's training path.

### Finish the visual and language gradient paths

For this derivation, consider one example and one head; sum parameter gradients over batch in a batched implementation. Write $\mathbf{G}_S=\partial L/\partial\mathbf{S}$ with shape $(T,N)$. Because $\mathbf{K}=\mathbf{Z}\mathbf{W}_K$ and $\mathbf{V}=\mathbf{Z}\mathbf{W}_V$, visual features receive **two** contributions:

$$
\begin{aligned}
\mathbf{G}_Z&=\mathbf{G}_K\mathbf{W}_K^{\mathsf T}
+\mathbf{G}_V\mathbf{W}_V^{\mathsf T},\cr
\mathbf{G}_H&=\mathbf{G}_Q\mathbf{W}_Q^{\mathsf T},\cr
\nabla_{\mathbf{W}_K}L&=\mathbf{Z}^{\mathsf T}\mathbf{G}_K,
\qquad
\nabla_{\mathbf{W}_V}L=\mathbf{Z}^{\mathsf T}\mathbf{G}_V.
\end{aligned}
$$

The first visual path changes **where** text reads; the second changes **what** is read. $\mathbf{G}_Z$ has shape $(N,D_v)$ and $\mathbf{G}_H$ has shape $(T,D_t)$. Other blocks and residual paths add their own gradients.

The lab now compares manual Q/K/V gradients with autograd for a non-square $2\times4$ attention matrix, including blocked keys.

A mask blocks contribution from valid finite padded values; it is not a NaN sanitizer. The dot product may see NaNs before the score mask, and $0\cdot\mathrm{NaN}$ in a value sum is still NaN. The checked wrapper rejects nonfinite inputs and all-masked examples. A different application could sanitize known padding **before** attention, but must not silently erase corrupt real evidence.

## 5. Three architectures, three information paths

| Connector | How vision reaches language | Main tradeoff |
|---|---|---|
| Projected prefix | Map visual tokens to text width and prepend them to a decoder sequence | Simple integration; visual tokens occupy self-attention context and cache |
| Cross-attention | Text queries read a separate visual memory | Separate visual length; extra modules and cross-attention computation |
| Learned-query resampler | A fixed number of learned queries compress visual tokens before connection | Controls token budget; may discard fine details |

For a causal prefix decoder, text can read preceding image tokens. Whether image tokens see each other bidirectionally depends on the chosen mask and visual encoder. “Prefix” alone does not define the entire mask.

For direct cross-attention, a text position can read all available image tokens while its text self-attention remains causal. For online video, “all available” must exclude future frames; image and time visibility are separate contracts.

## 6. Runnable shape and gradient check

```python
import torch
from torch import nn
torch.manual_seed(153)
layer = nn.MultiheadAttention(8, 2, dropout=0, batch_first=True)
text = torch.randn(2, 3, 8, requires_grad=True)
visual = torch.randn(2, 5, 8, requires_grad=True)
padding = torch.tensor(False, False, False, True, True).expand(2, -1)
out, weights = layer(text, visual, visual, key_padding_mask=padding)
out.square().mean().backward()
assert out.shape == (2, 3, 8)
assert weights.shape == (2, 3, 5)  # averaged over heads by default
assert visual.grad[:, 3:].abs().max() == 0
```

Here `True` means **blocked** for `nn.MultiheadAttention.key_padding_mask`. Do not transfer that polarity blindly to a different attention API.

The full lab also changes padded visual tokens by a large amount and verifies unchanged output. Jointly permuting keys, values, and their padding mask also preserves the readout. This permutation test concerns already-encoded tokens; it does not imply that rearranging raw image patches before position encoding preserves meaning.

## 7. What attention weights do not prove

A large weight means a large coefficient in one intermediate mixture. It is not a proof that a region caused the final answer or that the answer is factual. Value magnitudes, other heads, residual paths, and later layers also matter.

Test grounding by interventions: replace images, remove regions with a justified protocol, swap descriptions, and measure answer changes. Be careful: an intervention can itself create OOD inputs. Blank-image failure is informative but not a complete causal explanation.
