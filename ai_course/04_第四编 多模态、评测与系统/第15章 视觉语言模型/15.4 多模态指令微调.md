## 1. From matching to answering

Contrastive learning trains compatibility. Instruction tuning trains conditional responses: given an image and a question, produce a suitable answer. This adds a language-generation objective and a supervision-format problem.

The central question is not just “Can loss decrease?” It is “Which outputs are supervised, which inputs are visible, and does the model use the visual evidence?” A dataset where every question has the same answer can produce excellent training loss while teaching no vision at all.

Our experiment uses a real trainable image encoder plus a tiny causal text decoder with cross-attention. It is trained jointly from scratch on a two-answer synthetic task. This demonstrates the training mechanics; it is not the adaptation of a broadly pretrained LLM.

## 2. Define the conditional probability before the loss

For image $I$, prompt tokens $\mathbf{q}$, and answer tokens $a_1,\ldots,a_K$, autoregression gives

$$
p_\theta(a_1,\ldots,a_K\mid I,\mathbf{q})
=\prod_{k=1}^{K}
p_\theta(a_k\mid I,\mathbf{q},a_{<k}).
$$

Here $\theta$ collects all trainable parameters; $a_{<k}$ means earlier answer tokens. Include an end-of-sequence token so the model learns when to stop.

Taking negative logs changes the product into a sum:

$$
L_{\mathrm{answer}}
=-\frac{1}{K}\sum_{k=1}^{K}
\log p_\theta(a_k\mid I,\mathbf{q},a_{<k}).
$$

For a batch with different response lengths, choose whether to average over all valid response tokens or average each example's mean. These are different objectives. Our experiment uses the first; its examples happen to have equal lengths.

## 3. Shifted targets, with actual indices

Use vocabulary IDs: PAD=0, BOS=1, QUESTION=2, HORIZONTAL=3, VERTICAL=4, EOS=5. A horizontal example is serialized as

```text
Full sequence: [BOS, QUESTION, HORIZONTAL, EOS]
Model input:   [BOS, QUESTION, HORIZONTAL]
Targets:       [ignore, HORIZONTAL, EOS]
```

The logit at QUESTION predicts HORIZONTAL. The logit at HORIZONTAL predicts EOS. The BOS logit would predict the prompt token, but we ignore it.

Let $V$ be vocabulary size and $\mathbf{z}_{b,t}\in\mathbb{R}^{V}$ be vocabulary logits, $y_{b,t}$ the next-token target, and $m_{b,t}\in\{0,1\}$ the response mask. If $M=\sum_{b,t}m_{b,t}>0$,

$$
L=-\frac{1}{M}\sum_{b,t:m_{b,t}=1}
\log\mathrm{softmax}(\mathbf{z}_{b,t})_{y_{b,t}}.
$$

Select valid positions before computing CE if ignored positions can contain invalid labels or nonfinite logits. An all-ignored batch has no supervision; explicitly reject or skip it.

中文确认：loss mask 决定“哪些输出位置计分”，causal mask 决定“每个位置能看见什么”。这两个 mask 不能互相替代。

## 4. Why image features still receive gradients

Ignoring the prompt-position loss does not detach prompt hidden states. An answer logit depends on earlier prompt states through self-attention and on image states through cross-attention. Chain rule sends gradients along those paths.

For answer loss $L$, visual features $\mathbf{Z}=f_\psi(I)$, and connector parameters $\phi$, the gradient to the vision encoder is schematically

$$
\nabla_\psi L=
\left(\frac{\partial\mathbf{Z}}{\partial\psi}\right)^{\mathsf T}
\nabla_{\mathbf{Z}}L.
$$

This equation means “multiply local sensitivities along the existing graph”; the Jacobian need not be materialized. If $\psi$ is frozen, it is not updated. If $\phi$ is trainable, it can still adapt the frozen visual representation.

Common training schedules first align a connector with pretrained components and then instruction-tune selected components. The schedule, data mixture, and freeze policy are design choices, not universal laws. Joint training is simpler for our tiny randomly initialized model.

## 5. A hand loss example

Suppose the horizontal-answer probability is 0.8 and the following EOS probability is 0.5. There are two supervised tokens:

$$
L=-\frac{\log0.8+\log0.5}{2}
=-\frac{\log0.4}{2}\approx0.4581.
$$

The probability of the entire correct two-token response is 0.4, not the average 0.65. A low average token loss and a high exact-response success rate are related but different measurements.

```python
import torch
import torch.nn.functional as F
logits = torch.tensor([[[9., 0., 0.],
                        [0., 2., 0.],
                        [0., 0., 2.]]], requires_grad=True)
targets = torch.tensor(-100, 1, 2)
active = targets != -100
loss = F.cross_entropy(logits[active], targets[active])
loss.backward()
assert logits.grad[:, 0].abs().max() == 0
assert logits.grad[:, 1:].abs().sum() > 0
```

This block proves only the local loss-mask behavior. The full lab additionally checks nonzero vision-encoder gradients.

## 6. What the full experiment actually does

The companion trains on 96 noisy $8\times8$ bar images and evaluates on 64 independently generated images. A TinyViT supplies 16 visual tokens; the text block contains causal self-attention, image cross-attention, an FFN, and a six-token vocabulary head.

At evaluation it supplies only BOS and QUESTION, generates an answer, then feeds that prediction back to generate EOS. Exact match requires both tokens to be correct. This is stricter than giving the true answer as input and only checking teacher-forced logits.

Four checks matter:

1. The ignored BOS output has zero local logit gradient.
2. The image projection receives nonzero loss gradients.
3. Changing a future teacher-forced answer does not change earlier logits.
4. Blanking or swapping images changes the measured task performance.

Swapped-image output is scored against the **original** labels to expose image dependence. A model following the new image should intentionally perform poorly under those old labels. It would be wrong to describe this as a normal test-set robustness score.

### Trace the actual 6,214-parameter decoder

For batch $B$ and text length $T$, visual tokens are $(B,16,16)$; text embeddings and states are $(B,T,16)$; vocabulary logits are $(B,T,6)$. The model contains:

- image encoder without its 34-parameter classifier: $2,626-34=2,592$;
- token embedding: $6\cdot16=96$; text positions: $5\cdot16=80$;
- self-attention and cross-attention: $2\cdot1,088=2,176$;
- three LayerNorms: $3\cdot32=96$;
- FFN: 1,072; output head: $16\cdot6+6=102$.

The sum is 6,214. The text FFN uses GELU; the image encoder's FFN uses ReLU.

The implementation supports equal-length, **unpadded** text batches with $1\leq T\leq5$. PAD exists as a vocabulary ID but is rejected as an input. General variable-length batching requires a text key-padding mask and a valid-output loss mask; defining a PAD ID alone does not implement those mechanisms.

The bar generator alternates labels by row to obtain balance. Row indices are not model inputs. The lab permutes the evaluation batch and checks that predictions follow the images, not their batch positions. It also scores swapped images against their **new** labels. Poor accuracy against old labels plus good accuracy against new labels is stronger evidence of the intended intervention than an old-label drop alone.

The safe loss additionally tests ignored nonfinite **output leaves**. This does not establish that NaNs inside an upstream network are harmless: invalid internal activations can poison parameter gradients even if some final outputs are unscored.

For variable response lengths, suppose one answer has one token with loss 2 and another has three tokens with losses 0.5 each. Token averaging gives $(2+1.5)/4=.875$; example averaging gives $(2+.5)/2=1.25$. Specify which learning objective your reduction implements.

## 7. Formatting and supervision beyond the toy

Real examples need explicit associations between image placeholders and actual images. For several images, record their order and which question refers to which image. For videos, record frame timestamps and sampling; a frame list without time can lose motion meaning.

Avoid captions that accidentally disclose the target, answer text in image filenames passed to the model, duplicated scenes across splits, and evaluation using a question template identical to every training example while claiming open-ended instruction following.

Multi-turn examples may supervise several assistant spans. Image tokens and user turns normally remain context. Padding should not be an answer target, and the model must not read a future answer through a misplaced mask.

Licensing, privacy, consent, and demographic coverage are part of dataset construction. The local synthetic lab avoids these data-use issues; it does not solve them for a real collection.

## 8. Failure analysis and exercises

A grounded model can still hallucinate outside its two known answers. Our vocabulary cannot even express “unknown.” Do not generalize from exact bar orientation to object counting or rich visual reasoning.

1. Derive targets and masks for two assistant turns separated by a user question.
2. Reproduce the numerical response loss and compare token mean with sequence probability.
3. Train a text-only baseline on the balanced toy labels. Explain the attainable performance without visual evidence.
4. Add an “ambiguous/unknown” class with a clear labeling rule; report coverage and error, not only accuracy.
5. Freeze the vision encoder after initial training and compare connector-only adaptation to full tuning on validation data.
6. Add a question that cannot be answered from the image. Specify the expected response before training.
