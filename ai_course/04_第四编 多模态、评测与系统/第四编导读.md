## 从第三编接下来学什么

前三编建立了张量、训练、Transformer 与语言模型基础。本编先把模型接到图像和时间序列，再学习如何证明改进可信、如何估算和优化资源，最后通过生成建模与安全专题形成研究入口。

主线是：**视觉表示 → 图文连接 → 时间与融合 → 可信评测 → 系统资源 → 生成与研究**。这里不把名词列表当作掌握，也不以“某技术流行”代替依赖关系。

## 本编阅读标准

每节按“问题 → 直觉 → 符号与 shape → 分步推导 → 数值例子 → 代码/实验 → 反例 → 习题 → 完成标准与英文总结”推进。你先自主阅读和实践，疑问集中反馈，不恢复低效的一问一答。

建议把长节拆成三个读写单元：先解释关键机制，再不看答案推导/实现，最后运行与改动实验。19.1、19.2 较长，可分多次完成。时间上限由你决定，不为赶章节牺牲理解。

## 实验入口与真实边界

运行方法、全部脚本、实际结果与验证记录

- 实际训练：TinyViT、双编码器 toy 对比学习、带图像 cross-attention 的微型文本 decoder、XOR 模型、三种子交互特征消融、二维 VAE/GAN/DDPM。
- 机制验证：patch/卷积等价、对比 loss 梯度、padding/causal 隔离、Gaussian KL、DDPM 正向矩、量化误差和不等 token 数梯度。
- 明确模拟：评测候选输出、安全提案、系统峰值参数与分布式 rank；它们没有调用真实 LLM、工具、GPU 集群或付费 API。
- 未实现：自然语言 CLIP 预训练、通用多模态 LLM 指令微调、真实视频训练、GPU AMP、整数加速内核、多机多卡通信、条件扩散 guidance。正文说明其机制和扩展路径。

图与脚本保留真实不足：短程 GAN 训练未恢复双峰分布；VAE 增加完整观测采样图，并解释单位观测方差与数据方差 .1225 的不匹配。每节新增默认折叠的 self-check，先自主推导、再展开核对。

## 本编应留下的四类成果

1. 多模态机制笔记：能从像素一路解释到响应 loss，并证明没有未来信息泄漏。
2. 评测报告：假设、数据划分、baseline、切片、置信区间、错误案例和明确决策。
3. 系统账本：参数/梯度/优化器/激活/cache；算术估算与真实计时分开。
4. 专题实验提案：生成、后训练、效率、可靠性或可解释性任选一个小问题，列出可证伪假设、预算和复现步骤。

这些是逐步积累研究/工程能力的证据，不是进入某家公司的录用承诺。
