## 1. Motivation: exchanging information is only part of computation

Attention lets positions read other positions. A Transformer also needs to transform the resulting features, preserve information across depth, and control numerical scale.

A typical block combines multi-head attention, a position-wise feed-forward network (FFN), residual additions, and normalization. A repeated stack provides alternating position mixing and feature transformation.

## 2. Derive the position-wise FFN from the MLP

For token vector $\mathbf{x}\in\mathbb{R}^{D}$, expand to width $D_{\mathrm{ff}}$, apply a nonlinearity, and project back:

$$
\mathrm{FFN}(\mathbf{x})
=\mathbf{W}_2\phi(\mathbf{W}_1\mathbf{x}+\mathbf{b}_1)+\mathbf{b}_2.
$$

Here $\mathbf{W}_1:(D_{\mathrm{ff}},D)$ and $\mathbf{W}_2:(D,D_{\mathrm{ff}})$; the biases have shapes $\mathbf{b}_1:(D_{\mathrm{ff}},)$ and $\mathbf{b}_2:(D,)$. The activation $\phi$ acts on each intermediate coordinate. The same parameters are used at every position.

The expansion gives the nonlinearity more intermediate features to work with. The return to width $D$ makes a residual addition possible.

Without the activation, the two maps collapse into one affine map. FFN does not directly mix time positions; attention supplies that interaction.

## 3. GELU and gated feed-forward variants

ReLU keeps positive inputs and zeros negative inputs. GELU smoothly weights an input using a Gaussian cumulative distribution:

$$
\mathrm{GELU}(x)=x\Phi(x),
$$

where $\Phi(x)$ is the probability a standard normal variable is at most $x$. This describes a smooth deterministic activation, not random sampling during a forward pass.

A gated alternative computes two branches and multiplies them. One common form is

$$
\mathrm{SwiGLU}(\mathbf{x})
=\mathbf{W}_{o}\left[
\mathrm{SiLU}(\mathbf{W}_{g}\mathbf{x})
\odot(\mathbf{W}_{u}\mathbf{x})
\right],
\quad \mathrm{SiLU}(x)=x\sigma(x).
$$

Here $\sigma(x)=1/(1+\exp(-x))$ is sigmoid; $\odot$ is elementwise multiplication. If the hidden width is $H$, then $\mathbf{W}_g,\mathbf{W}_u:(H,D)$ and $\mathbf{W}_o:(D,H)$. Both branches produce $H$ coordinates, so their elementwise product is defined. Biases are omitted in this expression.

The gate is learned and content-dependent. With equal intermediate width this uses three matrices instead of two, so comparing equal parameter budgets may require adjusting the width. Different Transformers use different choices; there is no universal FFN recipe.

## 4. LayerNorm operates on each token's feature coordinates

Why center and rescale? A branch should respond to patterns across features without having to compensate for every common offset or scale change in its input. LayerNorm computes statistics from the current token, removes its mean, and rescales its centered spread. Learned scale/shift then let training choose a useful output range. This is a design motivation, not a claim that discarding a common shift is always desirable; the residual stream provides another route around the normalized branch.

For a token $\mathbf{x}\in\mathbb{R}^{D}$, first calculate its mean and variance, then normalize:

$$
\mu=\frac1D\sum_rx_r,\quad
v=\frac1D\sum_r(x_r-\mu)^2,\quad
\mathrm{LN}(\mathbf{x})
=\boldsymbol{\gamma}\odot\frac{\mathbf{x}-\mu}{\sqrt{v+\varepsilon}}
+\boldsymbol{\beta}.
$$

The learned scale $\boldsymbol{\gamma}$ and shift $\boldsymbol{\beta}$ have dimension $D$. The positive scalar $\varepsilon$ prevents division by zero and limits amplification when variance is tiny. The variance uses divisor $D$, not $D-1$, because we normalize this vector rather than estimate a population variance from an unbiased sample.

For $\mathbf{x}=(1,2,3)^{\mathsf T}$, $\mu=2$, $v=2/3$, and, temporarily ignoring $\varepsilon$ with $\boldsymbol{\gamma}=\mathbf{1},\boldsymbol{\beta}=\mathbf{0}$, the output is approximately $(-1.2247,0,1.2247)^{\mathsf T}$. Adding 10 to every input coordinate leaves it unchanged. With nonzero $\varepsilon$, unit variance is approximate; with learned affine parameters, output mean/variance need not be zero/one.

In a tensor $(B,T,D)$, `LayerNorm(D)` does not pool across examples or positions. For the same token vector, its normalization is independent of batch size and is computed the same way in training and evaluation.

RMSNorm uses the root mean square without subtracting the mean:

$$
\mathrm{RMSNorm}(\mathbf{x})
=\boldsymbol{\gamma}\odot
\frac{\mathbf{x}}{\sqrt{D^{-1}\sum_rx_r^2+\varepsilon}}.
$$

The denominator measures magnitude about zero, rather than spread about a learned token mean. For $\mathbf{x}=(2,2,2)^{\mathsf T}$ and unit scale, LayerNorm outputs zero, whereas RMSNorm outputs approximately $(1,1,1)^{\mathsf T}$ (ignoring $\varepsilon$). This exposes the distinction without relying on a timing comparison.

It is a different normalization, not merely a faster spelling of LayerNorm. Many implementations omit its bias. Both normalize input-dependent statistics, and gradients pass through those statistics.

## 5. Residuals preserve a path through the stack

For a sublayer $\mathcal F$, the residual form is $\mathbf{y}=\mathbf{x}+\mathcal F(\mathbf{x})$. Its input gradient includes a direct term plus a branch term, as derived in 05.2.

With **Pre-LN**, normalize before each sublayer:

$$
\begin{aligned}
\mathbf{u}&=\mathbf{x}+\mathrm{MHA}(\mathrm{LN}_1(\mathbf{x})),\\
\mathbf{y}&=\mathbf{u}+\mathrm{FFN}(\mathrm{LN}_2(\mathbf{u})).
\end{aligned}
$$

For $\mathbf{x}:(B,T,D)$, each normalization, attention read after its output projection, residual sum, and FFN output has the same shape. In the FFN only the intermediate activation expands to $(B,T,D_{\mathrm{ff}})$.

中文提示：一个 block 不是把 attention 的输出直接当最终答案。它先把读到的信息写回残差流，再用每个位置共享的 MLP 变换特征；两个加法都要求最后维度回到 $D$。

With **Post-LN**, normalize after each residual addition. Chapter 10 derives how this changes gradient paths.

A Pre-LN stack often has a final normalization before the output head. Residual streams are otherwise not necessarily normalized after every block.

## 6. Dropout and training mode

Dropout may be applied to attention weights, attention outputs, or FFN outputs depending on architecture. Record where it occurs.

The example uses zero dropout to make equality and causality tests deterministic. Training with dropout requires evaluation mode for validation; functional attention dropout must also receive the correct probability explicitly.

Normalization and residuals do not repair a wrong mask or a detached gradient path.

## 7. Runnable Pre-LN block

This block uses PyTorch's attention module only to isolate block composition. Section 09.4 implements the attention operations directly.

```python
import torch
from torch import nn

class PreLNBlock(nn.Module):
    def __init__(self, width=12, heads=3, ff_width=24):
        super().__init__()
        self.norm1 = nn.LayerNorm(width)
        self.attn = nn.MultiheadAttention(width, heads, dropout=0, batch_first=True)
        self.norm2 = nn.LayerNorm(width)
        self.ffn = nn.Sequential(nn.Linear(width, ff_width), nn.GELU(),
                                  nn.Linear(ff_width, width))

    def forward(self, x):
        z = self.norm1(x)
        blocked = torch.ones(x.shape[1], x.shape[1], dtype=torch.bool, device=x.device).triu(1)
        read, _ = self.attn(z, z, z, attn_mask=blocked, need_weights=False)
        u = x + read
        return u + self.ffn(self.norm2(u))

torch.manual_seed(28)
block = PreLNBlock().double()
x = torch.randn(2, 5, 12, dtype=torch.float64, requires_grad=True)
out = block(x)
assert out.shape == x.shape
out.square().mean().backward()
assert all(p.grad is not None and torch.isfinite(p.grad).all() for p in block.parameters())

# FFN is position-wise: perturbing one token cannot change another FFN output.
with torch.no_grad():
    y = block.ffn(x)
    changed = x.detach().clone()
    changed[:, 3] += 4
    changed_y = block.ffn(changed)
torch.testing.assert_close(y[:, :3], changed_y[:, :3])
torch.testing.assert_close(y[:, 4:], changed_y[:, 4:])

sample = torch.randn(2, 4, 12, dtype=torch.float64)
norm = nn.LayerNorm(12, elementwise_affine=False).double()
manual = (sample - sample.mean(-1, keepdim=True)) / (
    sample.var(-1, unbiased=False, keepdim=True) + norm.eps).sqrt()
torch.testing.assert_close(norm(sample), manual)
print("block shape, parameter gradients, and FFN locality verified")
```

## 8. Parameter accounting

A two-layer biased FFN has $2DD_{\mathrm{ff}}+D_{\mathrm{ff}}+D$ parameters. Two affine LayerNorms add $4D$. Combine with the $4D^2+4D$ attention parameters to count this block.

Activations, masks, and attention maps consume memory but are not trainable parameters. Width and sequence length affect these categories differently.
