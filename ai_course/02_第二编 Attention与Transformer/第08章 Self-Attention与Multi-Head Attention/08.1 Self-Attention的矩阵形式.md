# 08.1 Self-Attention as Batched Matrix Computation

第二编目录 · 本章导读

> Prerequisites: Chapter 07 and Part I shape conventions. Goal: connect per-query attention to token mixing across a batch.

## 1. Motivation: every token needs its own contextual read

A sentence contains multiple positions, and each position may need different information. Instead of running a Python loop over queries, stack them into a matrix and perform all score and read computations together.

Let input $\mathbf{X}\in\mathbb{R}^{B\times T\times D}$ contain $B$ examples, $T$ positions per example, and $D$ features per position. Attention mixes positions **within each example**, not across unrelated batch elements.

## 2. Derive projected shapes from ordinary linear layers

Using the PyTorch-compatible weight orientation, let $\mathbf{W}_Q,\mathbf{W}_K\in\mathbb{R}^{d_k\times D}$ and $\mathbf{W}_V\in\mathbb{R}^{d_v\times D}$. Omit bias temporarily:

$$
\mathbf{Q}=\mathbf{X}\mathbf{W}_Q^{\mathsf T},
\quad
\mathbf{K}=\mathbf{X}\mathbf{W}_K^{\mathsf T},
\quad
\mathbf{V}=\mathbf{X}\mathbf{W}_V^{\mathsf T}.
$$

Each projection independently transforms the final feature axis. Shapes become $(B,T,d_k)$, $(B,T,d_k)$, and $(B,T,d_v)$.

For each example, score query $i$ against key $j$:

$$
S_{n,i,j}=\frac{1}{\sqrt{d_k}}\sum_r Q_{n,i,r}K_{n,j,r}.
$$

The batch index $n$ is never summed. The resulting shape is $(B,T,T)$.

## 3. The two time axes have different roles

The first $T$ axis indexes queries; the second indexes keys. They happen to have the same length in self-attention, which can conceal a transposition mistake.

Apply softmax on the key axis, then use it to sum value rows:

$$
A_{n,i,j}=
\frac{\exp(S_{n,i,j})}{\sum_{\ell}\exp(S_{n,i,\ell})},
\qquad
O_{n,i,c}=\sum_j A_{n,i,j}V_{n,j,c}.
$$

Output shape is $(B,T,d_v)$. In cross-attention the unequal lengths $(T_q,T_k)$ make these roles easier to see.

`torch.matmul` and `@` broadcast leading dimensions, so correctly matching batch axes is still your responsibility.

### A two-token matrix example you can check by hand

Ignore batching and use one feature per Q/K/V vector: $d_k=d_v=1$. Let

$$
\mathbf{Q}=\begin{bmatrix}0\\\log 3\end{bmatrix},
\quad
\mathbf{K}=\begin{bmatrix}1\\0\end{bmatrix},
\quad
\mathbf{V}=\begin{bmatrix}2\\8\end{bmatrix}.
$$

Then the two matrix products perform different reductions:

$$
\mathbf{S}=\mathbf{Q}\mathbf{K}^{\mathsf T}
=\begin{bmatrix}0&0\\\log 3&0\end{bmatrix},
\quad
\mathbf{A}
=\begin{bmatrix}1/2&1/2\\3/4&1/4\end{bmatrix},
\quad
\mathbf{O}
=\begin{bmatrix}5\\3.5\end{bmatrix}.
$$

The first query reads the mean. The second reads more of the first value. Each **row** sums to one; columns sum to $1.25$ and $0.75$ and need not sum to one. Attention allocates a separate read budget per query, not one shared budget for all queries.

## 4. Token mixing versus feature mixing

A linear layer or position-wise MLP transforms each token independently using shared parameters. It mixes feature coordinates but does not access a neighboring token.

Attention's matrix $\mathbf{A}$ mixes positions. Its weights depend on the current input, so the mixing differs between examples and queries.

The product $\mathbf{A}\mathbf{V}$ is linear in values **if weights are held fixed**. The entire attention layer is generally nonlinear in $\mathbf{X}$ because $\mathbf{A}$ also depends on $\mathbf{X}$.

## 5. Prove permutation equivariance without positional information

Consider one example and a permutation matrix $\mathbf{P}\in\mathbb{R}^{T\times T}$ that reorders tokens. Replace $\mathbf{X}$ by $\mathbf{P}\mathbf{X}$. Shared projections give $\mathbf{Q}'=\mathbf{P}\mathbf{Q}$, and similarly for K and V.

The score matrix becomes

$$
\mathbf{S}'=\mathbf{P}\mathbf{S}\mathbf{P}^{\mathsf T}.
$$

Reordering rows and columns also reorders row-wise softmax:

$$
\mathbf{A}'=\mathbf{P}\mathbf{A}\mathbf{P}^{\mathsf T}.
$$

Therefore

$$
\mathbf{O}'=\mathbf{A}'\mathbf{V}'
=\mathbf{P}\mathbf{A}\mathbf{P}^{\mathsf T}\mathbf{P}\mathbf{V}
=\mathbf{P}\mathbf{O}.
$$

The outputs move with their tokens: **equivariance**, not identical output order. If outputs are subsequently averaged, that pooled representation is permutation invariant.

This proof assumes no fixed positional encoding, no index-dependent mask, and no unmatched dropout randomness. A causal mask supplies ordering constraints, so arbitrary token permutations with the same causal mask do not satisfy this proof.

## 6. Runnable experiment: vectorization and an invariance boundary

```python
import math
import torch
from torch import nn

torch.manual_seed(24)
B, T, D, dk, dv = 2, 4, 6, 3, 5
X = torch.randn(B, T, D, dtype=torch.float64)
q = nn.Linear(D, dk, bias=False).double()
k = nn.Linear(D, dk, bias=False).double()
v = nn.Linear(D, dv, bias=False).double()

def attend(inputs):
    Q, K, V = q(inputs), k(inputs), v(inputs)
    scores = Q @ K.transpose(-2, -1) / math.sqrt(dk)
    weights = scores.softmax(-1)
    return weights @ V, weights

output, weights = attend(X)
loop_output = torch.empty_like(output)
for n in range(B):
    for i in range(T):
        query_scores = torch.stack([(q(X[n, i]) * k(X[n, j])).sum()
                                    for j in range(T)]) / math.sqrt(dk)
        loop_output[n, i] = (query_scores.softmax(0)[:, None] * v(X[n])).sum(0)
torch.testing.assert_close(output, loop_output)

permutation = torch.tensor([2, 0, 3, 1])
reordered, _ = attend(X[:, permutation])
torch.testing.assert_close(reordered, output[:, permutation])
torch.testing.assert_close(reordered.mean(1), output.mean(1))

changed = X.clone()
changed[1] += 100.0
unchanged_first_example, _ = attend(changed)
torch.testing.assert_close(unchanged_first_example[0], output[0])
print("output / weights:", output.shape, weights.shape)
print("vectorization, equivariance, and batch isolation verified")
```

## 7. Mistakes and experiments

A symmetric shape does not imply a symmetric meaning. Softmax on the query axis is usually a bug here, even though dimensions and row counts look plausible.

Modify one token and inspect which outputs change. Unlike a position-wise MLP, unrestricted attention may change every output. Then add a causal mask in 08.3 and check the permitted boundary.

Do not flatten batch and sequence into one axis before attention unless cross-example interaction is explicitly intended.
