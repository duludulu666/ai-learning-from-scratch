每个 `lab_章_节.py` 对应一节课件。目录内的 `transformer_core.py` 保存 09.4 的完整模型，`cache_core.py` 保存 10.2 的推理缓存实现。保留这些文件在同一目录，09.4、10.2、10.3 的脚本会复用它们。

在 PowerShell 中，例如：

```powershell
& 'D:\miniconda3\envs\d2l\python.exe' 'C:\Users\关俊烨\Documents\Obsidian Vault\AI学习手册\第二编 Attention与Transformer\配套实验\lab_09_4.py'
```

可以从任意工作目录运行脚本，也可以在编辑器中选择同一解释器。将课件代码复制到 notebook 时，需要一并定义依赖类，或把配套模块加入该 notebook 的模块搜索路径。

## 本次实测结果与解释

07.3 中 key/query 维数为 4、16、64、256 时，未缩放点积方差约为 3.93、15.54、63.28、253.04；除以维数平方根后约为 0.98、0.97、0.99、0.99。该实验的输入遵循独立、零均值、单位方差假设。手写 Q/K/V 梯度均与 autograd 匹配；进一步验证了三组投影权重和偏置、共享输入梯度，并通过一个权重的中心有限差分检查。

08.2 与 PyTorch MultiheadAttention 在相同权重下的前向、逐头权重、输入梯度与全部参数梯度匹配。08.3 的未来 key/value 扰动不影响更早输出，全遮挡与混合遮挡行的反向梯度有限且符合零读取策略。09.3 增加去掉 mask 后扰动能被检测到的负对照；09.4 验证整个多层模型的未来输入扰动不影响前面 logits。

09.4 的模型为 18,240 参数，四符号 prompt 复制任务。4096 个可能 prompt 中，用固定随机划分的 512 个训练、128 个验证、128 个测试，三个集合不重叠。验证交叉熵从约 2.397 降至 0.000648；最佳验证 checkpoint 的测试交叉熵约 0.000629，teacher-forced token accuracy 和自由生成整段 exact match 均为 100%。

新增无上下文基线为 9,664 参数：相同宽度、两层残差 FFN，但不跨位置读取。它在同一数据划分、600 更新、相同 batch 顺序、优化器设置和验证选择规则下单独训练；最佳验证交叉熵约 2.10161，测试交叉熵约 2.10688，测试 token accuracy 10.7422%，自由生成 exact match 0%。全体 4,096 个可能 prompt 的条件计数验证了 current-token-only 模型的总体准确率上限为 12.5%；有限测试子集不要求恰好等于该值。两种架构参数量不同，这不是等参数效率比较。

这个结果说明模型在该固定长度、固定符号表的小任务上学会了复制，并通过因果性检查。它不证明自然语言能力、任意长度外推或大模型推理能力。改变任务时应重新设计评测。

10.1 中输入梯度范数随深度和 normalization placement 变化，但并非每个深度都表现为 Pre-LN 大于 Post-LN。图中只记录一个随机初始化与探针，不能拿它直接代替训练稳定性的全面比较。零分支的 Jacobian 恒等式通过了独立验证。

10.2 用 chunk 长度 3、1、4 处理同一段输入，cached 与 full-prefix logits 最大差异约 $5.55\times10^{-16}$（float64）。逐步生成结果也相同；全段、逐 token、等长小块等划分也通过。错误 V batch、head 数、宽度、层数、长度、dtype、rank、超长输入与训练模式均按预期被拒绝。额外的在线 softmax 实验在大绝对分数下与 dense softmax read 匹配。

10.3 将位置表配置为长度 128，因此参数量为 21,824，与 09.4 的长度 16 配置不同。手工公式与实际参数数目完全一致。本次批量 4、长度 8/16/32/64 的 CPU 完整前向中位耗时约 0.30/0.38/0.48/0.93 ms。这些计时来自本机回归运行，可能受并行实验和系统负载影响，不能推断 GPU 或真实服务延迟。

## 如何用实验学习

先写下自己的预期，再运行断言与打印结果。修改一个因素后重跑，解释差异是公式、mask、shape、初始化、数据、计算量还是计时波动造成的。

可以优先做四个独立成果：attention backward 校验、多头+mask 实现、复制任务报告、KV cache 等价性测试。每个成果附一段英文解释和一个你主动构造的失败案例。
