# AI 深度学习教材

面向深度学习与 AI 的系统教材（AI 生成课件）：从 PyTorch 基础到 Transformer、LLM、多模态与评测系统。四编 19 章 63 节，每节配有 CPU 可运行的配套实验（`lab_xx.py`）。

## 目录结构

| 编 | 主题 | 章节 |
|---|---|---|
| 第一编 | 深度学习与 PyTorch | 第 01–06 章：环境与基础、监督学习、MLP 与反向传播、优化与训练稳定性、CNN、序列建模 |
| 第二编 | Attention 与 Transformer | 第 07–10 章：Attention 问题与直觉、Self-Attention、完整 Transformer、训练与效率 |
| 第三编 | 大语言模型 | 第 11–14 章：语言模型基础、预训练与 Scaling、微调对齐与推理、LLM 应用与可靠性 |
| 第四编 | 多模态、评测与系统 | 第 15–19 章：视觉语言模型、多模态融合、Evals、GPU 与训练系统、生成模型 |

## 学习路径

基础工具与数学 → PyTorch 与神经网络 → CNN 与视觉表示 → Attention 与 Transformer → 语言模型与 LLM → 多模态、评测与系统

## 配套实验

各编 `配套实验/` 目录下是每节对应的可运行脚本（NumPy / PyTorch，CPU 可跑），实验生成图见各编 `配套实验/figures/`。
